# 捏捏乐

手机上玩的解压小玩具，打开 `index.html` 就能用，不需要安装任何东西。

## 五种玩法

| 玩具 | 怎么玩 | 反馈 |
| --- | --- | --- |
| 史莱姆 | 拖拽拉扯、戳一戳、双指一起揉，"揉成团"可以重新团起来 | 黏糊糊的水声、细碎噼啪声、气泡啵啵声，拉得越快震动越强 |
| 冰山泥 | 按下去压碎表面的薄冰，按住越久碎得越多，划过去一路压碎；"重新结冰"让冰面恢复。有浅蓝冰山、深海蓝、薄荷冰、樱花冰、葡萄冰 5 种 | 清脆的"咔嚓"碎冰声和裂纹蔓延的噼啪声，每次压碎都有一串短震 |
| 捏捏 | 按住慢慢捏扁，松手后慢慢回弹（麻薯 / 桃桃 / 布丁 / 抹茶 / 芋泥） | 海绵沙沙声，捏得越扁震动越强，表情会变成 >< |
| 泡泡纸 | 点或者一路划过去捏爆 | 清脆的"啪"，每个泡泡一次短震；全部捏完自动换新 |
| 波普 | 一个个按下去，全部按完自动翻面 | 硅胶"咚"声，翻面有提示音和连续震动 |

## 声音和震动

- 所有声音都用 Web Audio 实时合成，每次都略有不同，不需要音频文件。第一次点屏幕后才会出声（浏览器限制）。
- 震动：安卓 Chrome 使用 `navigator.vibrate`；iPhone（iOS 18 及以上的 Safari）用系统开关控件触发轻触感，强度不能调。没有震动时画面会轻微抖动。
- 网址后面加 `#ice` 会直接打开冰山泥（`#slime`、`#squish`、`#wrap`、`#popit` 同理）。
- 右上角可以单独关闭声音或震动，设置会保存在本机。

## 装到手机桌面

把这个目录部署到任意静态网站（例如 GitHub Pages），用手机打开后：

- 安卓 Chrome：菜单 → 添加到主屏幕
- iPhone Safari：分享 → 添加到主屏幕

装好后像 App 一样全屏打开，也可以离线玩。

## 本地运行

```sh
python3 -m http.server 8000
# 打开 http://localhost:8000
```
